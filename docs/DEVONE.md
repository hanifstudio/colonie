# DevOne compatibility guide

The project/build is now **Colonie**. See [the current run guide](COLONIE.md).
Old `pnpm devone` source-launch aliases and existing `.devone` data/profile paths
remain compatible. Current app: `release/colonie/mac-arm64/Colonie.app`.

The historical DevOne artifact/commands in `PROGRESS.md` record the original
Codex-only baseline and are retained as evidence. Colonie's upgrade recipe
verifies continuity from that artifact; it does not operate on a live app.
